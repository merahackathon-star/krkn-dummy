Welcome to the NexusWeather API documentation.

## Features

* **Geocoding:** Convert city names to coordinates.
* **Weather:** Get real-time weather data.
* **FastAPI:** Built with modern Python frameworks.
* **CI/CD Ready:** Setup for GitHub Actions (`act`).

This documentation site is built using Hugo and the Docsy theme. It is designed to be easily updated by LLMs like Gemini in your CI/CD pipeline!
